# ゆとりログ

毎日のコンディションを記録し、心身の変化や仕事の負荷に早めに気づくためのセルフチェックアプリ。
医療的な診断ではなく、自己理解と相談の補助を目的とします。

- 設計書：[アプリ設計書 v1.0](docs/design_spec.html)（2026年11月8日更新）

## 使い方

ビルド不要の静的 Web アプリ（PWA）です。任意の静的サーバーで配信してください。

```sh
npm start        # = python3 -m http.server 8080 → http://localhost:8080/
npm test         # ロジックの単体テスト（Node.js 20 以降）
```

GitHub Pages などの HTTPS 環境で公開すると、スマートフォンのホーム画面に追加してオフラインでも使えます。

## 実装状況（設計書 8. 実装ロードマップ）

| 段階 | 状態 | 内容 |
| --- | --- | --- |
| Phase 1 記録基盤 | ✅ | 記録フォーム、日付切替、保存・編集・削除、入力途中の一時保存、履歴一覧 |
| Phase 2 分析画面 | ✅ | 7日／30日切替、複数系列グラフ（系列の表示切替・日付タップで値表示・未記録は欠損）、項目別平均、前期間との差 |
| Phase 3 関連分析 | ✅ | 業務量区分ごとの平均、睡眠と疲労の比較表示、休日の回復（休日前後の勤務日の比較）、件数表示とデータ不足判定 |
| Phase 4 振り返り支援 | 未着手 | 週次レポート、連続変化の検出、気づきメッセージ |
| Phase 5 運用改善 | 一部 | JSON バックアップ／読み込み、CSV 書き出し、オフライン対応、記録時刻のお知らせ（アプリ内表示のみ） |

## 設計書の「未決定事項」に対する暫定判断

| 項目 | 今回の実装 |
| --- | --- |
| 利用環境 | PWA（スマートフォン優先の Web アプリ） |
| 保存先 | 端末内のみ（ブラウザの localStorage）。外部送信なし |
| 認証 | なし（個人・端末内利用のため） |
| 必須項目 | コンディション5項目のうち1つ以上。ほかはすべて任意 |
| 総合スコア | その日に記録したコンディション項目の単純平均（画面に算出方法を表示） |
| 通知 | 指定時刻以降に未記録ならホームにお知らせを表示（既定 21:00）。プッシュ通知は未対応 |
| 休日の判定 | 記録画面で「勤務日／休日」を選ぶ方式 |
| データ不足 | 期間内の記録が3件未満なら平均・傾向を表示しない |

## 構成

```
index.html            画面の枠と下部ナビゲーション
css/style.css         Soft / Calm デザイン（ライト／ダーク）
js/model.js           データモデル・項目定義・総合スコア
js/store.js           端末内保存、エクスポート／インポート
js/analysis.js        分析（平均、前期間差、業務量・休日の比較）
js/chart.js           SVG 折れ線グラフ
js/app.js             各画面の描画とイベント処理
sw.js                 オフライン用キャッシュ
tests/                単体テスト（node:test）
```
